## 📌 Overview

Crowdfunding is the practice of funding a project or venture by collecting small contributions from a large number of people. This application provides a simple command-line interface (CLI) where users can register, log in, and manage fundraising projects.

## 🚀 Features

### Authentication System

#### User Registration

Users can create an account by providing:

* First Name
* Last Name
* Email Address
* Password
* Confirm Password
* Egyptian Mobile Phone Number (validated)

#### User Login

Registered users can log in using:

* Email Address
* Password

---

### Project Management

After logging in, users can:

#### Create a Fundraising Project

Each project contains:

* Title
* Details
* Total Target Amount
* Start Date
* End Date

Date validation is applied to ensure a valid campaign duration.

#### View Projects

* Display all available fundraising projects.

#### Edit Projects

* Users can update projects they created.

#### Delete Projects

* Users can remove their own projects.
